PDFs online

PDFs abertos via link (http/https) sao detectados automaticamente e abertos no visualizador proprio.

Para usar:

  1. PDF online: navegue ate o link, a extensao abre sozinha
  2. PDF local: use o botao acima para escolher o arquivo
  3. Clique em "Selecionar" no visualizador
  4. Clique no PDF para capturar texto
  5. Exporte para PDF ou TXT

Funcionalidades:

  • Visualizador baseado em PDF.js
  • Suporte a PDF online e local
  • Captura de texto por pagina
  • Exportacao formatada para PDF
  • Exportacao para TXT
  • Persistencia de excertos

Pre-requisitos

Antes de usar, voce precisa:

  1. Baixar as bibliotecas: python setup.py
  2. Criar o icone: converta icons/icon.svg para PNG 48x48

PDFs locais muito grandes (acima de alguns MB) podem nao carregar devido a limites de armazenamento do navegador.
