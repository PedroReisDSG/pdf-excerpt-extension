Para criar o icon-48.png:

1. Use o arquivo icon.svg como base
2. Converta para PNG 48x48 pixels
3. Ou crie seu proprio icone

Ferramentas online para conversao:
- https://cloudconvert.co/svg-to-png
- https://svgtopng.com/
- https://convertio.co/svg-png/

Ou use o GIMP/Photoshop para criar um icone personalizado.
